# 0.2.1 配布検証

検証日: 2026-10-23 / Windows 11 x64

- 検索・再生・ジャケット編集の既存統合テスト3件が成功。
- アイコンは16 / 20 / 24 / 32 / 40 / 48 / 64 / 96 / 128 / 256pxの10サイズ。
- 実行ファイルとフォームにアイコンを埋め込み、フォームの描画結果を確認。
- Inno Setup 6.7.3で配布用インストーラーを作成。
- 同じスクリプトの作業フォルダー用検証ビルドで、インストール、スタートメニュー相当とデスクトップ相当のショートカット、起動、音源読み込み、上書き再インストール、アンインストールを確認。
- ショートカットの実行先とアイコン参照先がアプリの実行ファイルと一致することを確認。
- アンインストール後にアプリとショートカットが削除され、別の保存先にあるライブラリデータと音源が保持されることを確認。

実行環境の制限により、通常のスタートメニューとアンインストール用レジストリへの登録は実機で完了まで検証していません。
検証時のみコンパイル時の `SmokeTestRoot` を指定し、ショートカット先を作業フォルダーに変更し、`CreateUninstallRegKey=no` としています。
配布用インストーラーにはこの検証用設定を含めず、通常のユーザー用スタートメニュー・デスクトップ・アンインストール登録を使用します。

インストーラーとアプリのコード署名は付与していません。
