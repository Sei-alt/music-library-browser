# GitHubへの追加準備

このフォルダーがリポジトリに追加するソース一式です。個人用の音楽データベースとは独立しています。

1. リポジトリの作業フォルダーに、このソース一式を配置します。
2. `README.md`とライセンス（GPL-2.0-or-later）を確認します。
3. `git status --short`などで、ソースと説明書だけが追加対象になっていることを確認します。
4. コミットしてリポジトリへ反映します。
5. 配布する場合、ビルドされたWindows用ZIP・対応するソースZIP・SHA256SUMSをリリース添付ファイルに使用します。

`runtime`、楽曲、データベース、フォルダーパスの設定、トークン、ジャケット変更のバックアップはコミット対象から除外しています。
実行データはユーザーのローカルアプリデータに作成します。
必要なソースと第三者ライセンスは、ソースZIPおよびWindows用ZIP内のソースZIPに含まれます。

公開先のリポジトリ作成・変更や、GitHubへのアップロードは別の操作です。
